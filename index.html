Двуязычный лендинг + ИИ-ресепшн для посуточной аренды

  • Форма → Cloudflare Worker → Telegram
  • ИИ-ресепшн для автоматических ответов гостям

AI-Plant

Генерация PDF-книги английских идиом

Автоматический конвейер учебных материалов: отбирает идиомы, ищет контексты в корпусе BNC, генерирует буквальные сюрреалистичные иллюстрации через gpt-image-2 и собирает PDF. Гипотеза: буквальные картинки запоминаются студентами лучше абстрактных.

  • Парсинг и фильтрация идиом из словаря
  • Поиск контекстов в SQLite-копии BNC
  • Генерация изображений через ProxyAPI / OpenAI
  • Сборка PDF с примерами, жанрами и переводами
  • Инкрементальный pipeline с возобновлением

BNC Search

Корпусный поисковый движок и словарь идиом

Конвейер для лингвистических исследований: парсинг Cambridge International Dictionary of Idioms из PDF в JSON, разметка, поиск вхождений в British National Corpus с сохранением контекстов, жанров и частотностей. Веб-приложение на Flask для поиска по корпусу.

  • Парсинг PDF-словаря: 1000+ headword, 7000+ идиом
  • Поиск в SQLite-индексе BNC (~13 ГБ)
  • Контексты, жанровые теги и частотности
  • Веб-интерфейс и REST API на Flask
  • Ручная и машинная разметка тональности

Alisa

Автоматическая иллюстрированная книга из plain text

Из неформатированного текста собирает готовую к публикации PDF-книгу: режет произведение на смысловые блоки, генерирует иллюстрации каждые ~2 страницы по сюжету, добавляет буквицы, заголовки и нумерацию. Протестировано на «Алисе в Стране чудес» на английском и русском.

  • Разбивка текста на главы и смысловые блоки

  • Вёрстка PDF с буквицами и нумерацией
  • Поддержка нескольких языков (EN / RU)
